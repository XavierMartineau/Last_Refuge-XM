# Ressources du projet

Toutes les ressources complémentaires sont regroupées dans `docs/` par type :

- `assets/audio/`, `assets/images/` et `assets/svg/` : médias du jeu.
- `assets/creation-personnage/` : SVG classés par catégorie, manifest et données non graphiques du créateur.
- `assets/svg/` classe les illustrations par usage (`accueil/`, `forge/`, `identite/`, `motifs/`, etc.).
- `css/` : styles classés par page et styles partagés dans `commun/`.
- `data/content.json` : textes principaux et commandes des pages publiques.
- `html/` : un dossier par page (choix du mode, hub solo dans `info/`, Options, DEV et créateur de personnage).
- `js/` : scripts classés par page, chargement des contenus et préférences partagés dans `commun/`.

Les pages `index.html` et `404.html` restent à la racine.
